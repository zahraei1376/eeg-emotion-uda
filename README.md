## Baseline Paper Reproduction

This directory documents the reproduction of the experimental results reported in:

**Imtiaz, M. N., & Khan, N. (2025).** Enhanced cross-dataset electroencephalogram-based emotion recognition using unsupervised domain adaptation. *Computers in Biology and Medicine, 184*, 109394.

**Original implementation:** https://github.com/RyersonMultimediaLab/EmotionRecognitionUDA

The baseline experiments use the original implementation provided by the paper's authors. The original source code is not redistributed in this repository.

This directory will document the experimental environment, reproduction steps, necessary configuration changes, and results obtained from the DEAP and SEED datasets.
